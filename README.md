# Матричный калькулятор

Приложение на PyQt6 для решения систем линейных алгебраических уравнений (СЛАУ),
работы с матрицами и визуализации результатов.

**Семестровая работа студента группы КБ-241.**

## Возможности

### Решение СЛАУ
- **Метод Гаусса** с частичным выбором ведущего элемента (с пошаговым выводом).
- **Метод Крамера** через определители.
- Поддержка **комплексных чисел** (`a+bi`).
- Пошаговое решение для метода Гаусса.

### Операции с матрицами
- **Обратная матрица** `A⁻¹`.
- **Определитель** `det(A)`.
- Проверки на невырожденность и квадратность.

### Графическая интерпретация
- **2D-график** для систем 2×2 — прямые и точка пересечения.
- **3D-график** для систем 3×3 — плоскости и точка пересечения.
- Экспорт графиков в PNG.

### История решений
- Сохранение матриц и решений в базу данных SQLite.
- Фильтр по методу, поиск по имени.
- Переименование, удаление, загрузка сохранённых матриц обратно в редактор.

### Работа с файлами
- Загрузка матриц из CSV.
- Валидация ввода на лету (подсветка невалидных ячеек).

## Установка и запуск

### Требования
- Python 3.10 или выше
- pip

### Шаги

1. **Клонируй репозиторий:**
   ```bash
   git clone https://github.com/ScaleVVWizard/matrix_solver.git
   cd matrix_solver
   ```

2. **Создай виртуальное окружение (рекомендуется):**
   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # Linux/macOS
   source venv/bin/activate
   ```

3. **Установи зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запусти приложение:**
   ```bash
   python main.py
   ```

При первом запуске автоматически создастся файл `matrix_solver.db` — база данных
для хранения истории решений.

## Сборка standalone-версии

Для сборки `.exe` используется **PyInstaller**.

### Установка PyInstaller

```bash
pip install pyinstaller
```

### Команда сборки (Windows)

Запусти из корня проекта:

```powershell
pyinstaller --onefile --windowed --name "MatrixCalculator" ^
    --add-data "main_window.ui;." ^
    --add-data "history_window.ui;." ^
    --add-data "plot_window.ui;." ^
    --add-data "logo.png;." ^
    --icon "logo.png" ^
    main.py
```

Для Linux/macOS замени `;` на `:` в `--add-data` и убери `--icon`.

### Результат

Готовый файл появится в папке `dist/`:
- **Windows:** `dist/MatrixCalculator.exe`
- **Linux/macOS:** `dist/MatrixCalculator`

### Важно

- Все ресурсы (`*.ui`, `logo.png`) встроены в `.exe` через `--add-data`.
- База данных `matrix_solver.db` создаётся **рядом с `.exe`** (при первом запуске).
- Для корректной работы `_MEIPASS`-путей в коде используется проверка
  `sys.frozen` во всех модулях, работающих с файлами (см. `main.py`,
  `database.py`, `history_window.py`, `plot_window.py`).

## Руководство пользователя

### 1. Ввод матрицы

1. Укажи **количество строк** и **столбцов** спинбоксами (2–8).
   - Последний столбец таблицы — вектор свободных членов **b**.
2. Заполни ячейки числами:
   - **Вещественные:** `5`, `-3.2`, `0.5`
   - **Комплексные:** `2+3i`, `-i`, `1.5-0.5i`
   - **Максимум по модулю:** 1 000 000
3. Невалидные ячейки подсвечиваются:
   - красный — ошибка формата
   - жёлтый — превышен лимит модуля

### 2. Решение СЛАУ

1. Выбери метод в выпадающем списке:
   - **Метод Гаусса**
   - **Метод Крамера**
2. Отметь чекбокс **«Показывать пошаговое решение»** (для Гаусса).
3. Нажми **«Решить»** (или `Ctrl+Enter`).

Результат выводится справа: вектор решения `x` и, если включено, шаги.

### 3. Операции с матрицами

- **«Обратная матрица»** — вычислит `A⁻¹` (только для квадратной невырожденной).
- **«Определитель»** — вычислит `det(A)`.

### 4. Сохранение и история

1. После решения нажми **«Сохранить»** (или `Ctrl+S`).
2. Введи имя матрицы — она запишется в БД вместе с решением.
3. **«История»** (`Ctrl+H`) — откроется окно со всеми сохранёнными записями.
   - **Фильтр по методу** и **поиск по имени**.
   - **«Загрузить»** — вернуть матрицу в редактор.
   - **«Переименовать»** — изменить имя (UPDATE в БД).
   - **«Удалить»** — убрать запись.

### 5. Графики

- **«Графики»** (`Ctrl+G`) — открывается окно с интерпретацией:
  - **2×2** → две прямые и точка пересечения.
  - **3×3** → три плоскости и точка пересечения.
- Для других размеров или комплексных чисел — сообщение о недоступности.
- **«Сохранить PNG»** — экспорт текущего графика.

### 6. Горячие клавиши

| Комбинация | Действие |
|---|---|
| `Ctrl+O` | Загрузить матрицу из CSV |
| `Ctrl+S` | Сохранить в историю |
| `Ctrl+H` | Открыть историю |
| `Ctrl+G` | Открыть графики |
| `Ctrl+Enter` | Решить систему |
| `Delete` | Очистить выделенную ячейку |
| `ПКМ` по ячейке | Контекстное меню (копировать/вставить/очистить) |

## Формат входных данных

### Загрузка из CSV

Обычный текстовый файл `.csv`:
- Числа разделены **запятой**.
- Каждая строка — уравнение.
- Последний столбец — свободные члены `b`.
- Без заголовков.

**Пример (система 3×3):**
```csv
2,1,1,7
1,3,2,13
1,2,4,17
```

Система:
```
2x₁ + 1x₂ + 1x₃ = 7
1x₁ + 3x₂ + 2x₃ = 13
1x₁ + 2x₂ + 4x₃ = 17
```

Решение: `x = (1, 2, 3)`.

**Пример (комплексная система):**
```csv
1+1i,0,2+2i
0,1-1i,2-2i
```

**Ограничения:**
- Размер: от 2×2 до 8×8.
- Формат чисел: как при ручном вводе (см. выше).

## Техническое задание

### Цель работы

Разработать десктопное приложение для решения систем линейных алгебраических
уравнений и выполнения базовых операций с матрицами, с графическим интерфейсом,
базой данных и визуализацией.

### Функциональные требования

1. **Решение СЛАУ** двумя методами:
   - Метод Гаусса с частичным выбором ведущего элемента.
   - Метод Крамера.
2. **Операции с матрицами:**
   - Обратная матрица.
   - Определитель.
3. **Поддержка комплексных чисел.**
4. **Графическая интерпретация** решений (2D/3D).
5. **История решений** в БД SQLite:
   - Сохранение, загрузка, переименование, удаление.
   - Фильтр по методу, поиск по имени.
6. **Импорт из CSV.**
7. **Валидация ввода** (запрет недопустимых символов, подсветка ошибок).
8. **Горячие клавиши** и **контекстное меню**.

### Нефункциональные требования

- Интерфейс создан в **QtDesigner** (три формы).
- Использование **не менее пяти различных виджетов**.
- **Стандартные диалоги** (QMessageBox, QFileDialog, QInputDialog).
- **Мультимедиа** (логотип на форме, иконка окна, сплэш-скрин).
- **Сборка standalone** версии через PyInstaller.
- Код соответствует **PEP8**, содержит docstring и комментарии.
